Picture a warehouse with thousands of items, dozens of orders coming in every hour, and several robots moving things around. Without a system, this is chaos — wrong items shipped, robots colliding for the same job, no visibility into what's happening. My project solves exactly this.

Standard 3-tier architecture: React talks to FastAPI, which reads and writes to SQLite. The bonus piece is the AGV simulator — a background async task that runs continuously, mimicking real robots picking up jobs and delivering them. To non-technical folks: frontend is what you see, backend is the brain, database is the memory, and the simulator is the robot's hands.

⚙️ Tech Stack

Backend

  • FastAPI — modern async Python web framework
  • SQLAlchemy — ORM for clean DB access
  • SQLite — embedded persistent storage
  • JWT — secure token-based auth
  • Pydantic — input validation

Frontend

  • React 18 — component-based UI
  • TypeScript — type safety end-to-end
  • Vite — lightning-fast dev server
  • Context API — auth state management
  • Fetch + custom client — typed API calls
Why this stack? Fast to build, type-safe, production-ready.
FastAPI gave me automatic Swagger docs and async support out of the box. React with TypeScript caught bugs at compile time before they ever shipped. SQLite kept the setup simple — and it can swap to PostgreSQL with one line change.

🧩 Challenges & Learnings

Async background simulator

Running a continuous task without blocking the API. Solved with FastAPI's lifespan handler.

Entity relationships

Modeling Orders ↔ AGVs ↔ Zones cleanly so each can be queried independently.

End-to-end auth

JWT generation on backend, secure storage and refresh on React side via Context.

Layered error handling

Validation at schema layer, business rules at service, global handler for the unexpected.

The trickiest part was the AGV simulator — making it run continuously without freezing the API. FastAPI's async lifespan handler solved it cleanly. The second was getting auth right end-to-end, especially handling token expiry on the React side.
