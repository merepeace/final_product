The Problem

  • Warehouses juggle thousands of orders & multiple robots
  • Manual coordination → errors, delays, lost stock
  • No real-time visibility into orders or AGV status
  • Idle robots while orders pile up

The Solution

  • One system to manage Products, Orders, Zones, AGVs
  • Secure login + role-based access
  • Auto-assigns orders to available AGVs
  • Real-time tracking + complete audit trail

Order Lifecycle

pending → validated → assigned → in-transit → delivered
  • User creates order with priority & destination
  • System validates + persists to DB
  • Simulator picks the next idle AGV
  • AGV moves item from source → destination zone
  • Status auto-updates; every step is logged

Challenges & Learnings

  • Designing clean relationships: Orders ↔ AGVs ↔ Zones
  • Async background simulator without blocking the API (FastAPI lifespan)
  • End-to-end auth: JWT on backend + token handling in React context
  • Validation & error handling at every layer (schemas, services, global handler)

Likely Audience Questions

  • Q: What if two orders need the same AGV?
    A: Queue + first-come-first-served per AGV.
  • Q: Can it scale?
    A: Yes — swap SQLite → Postgres, simulator → real AGV API.
  • Q: Is it secure?
    A: JWT auth on every endpoint + global error handler.
